# 🚇 Metro Ticket Generating System – ServiceNow

## 📌 Overview

The Metro Ticket Generating System is a ServiceNow-based application developed to digitize and streamline metro ticket booking. It enables users to book tickets by selecting their source station, destination station, and travel details. The system calculates the applicable fare and generates digital tickets with QR codes for a convenient booking experience.

Using ServiceNow capabilities such as Service Catalog, Flow Designer, and Notifications, the system automates the booking workflow, reduces manual effort, and improves the efficiency of the ticketing process.

## 🎯 Objectives

- Digitize and simplify metro ticket booking.
- Automate fare calculation based on selected stations and travel details.
- Generate digital tickets with QR codes.
- Automate booking workflows and confirmation notifications.
- Improve the efficiency and accessibility of the ticketing experience.

## ⚙️ Key Features

- **Station Selection:** Select source and destination stations.
- **Ticket Booking:** Submit booking requests through the Service Catalog.
- **Automatic Fare Calculation:** Calculate fares according to configured fare rules.
- **Digital Ticket Generation:** Generate tickets with QR codes and journey details.
- **Workflow Automation:** Automate booking processes using Flow Designer.
- **Notifications:** Provide booking confirmations and ticket information.
- **Ticket Records:** Store and manage ticket booking details in ServiceNow.

## 🛠️ Technologies Used

- ServiceNow Platform
- Service Catalog
- Flow Designer
- ServiceNow Notifications
- ServiceNow Tables and Forms
- QR Code Generation
